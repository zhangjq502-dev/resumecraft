# ResumeCraft

本地优先的 Markdown 桌面简历编辑器。Electron + React（实际版本见 package.json）+ TypeScript + SCSS Modules + Zustand。

## 开发
需要 Node.js 22.12+ 与 npm。

```sh
npm install
npm run dev
```

## 功能
- Markdown / GFM 编辑和实时预览，原始 HTML 与图片不参与渲染。
- 三种预设主题、字号和行高调整。
- 500ms 防抖保存本地 JSON 简历库，JSON 备份导入、导出（Cmd/Ctrl+S）。
- A4 PDF 导出，保留文字与链接。预览为连续纸张，实际分页以 PDF 为准。
- 渲染进程无 Node 权限，sandbox + contextIsolation；preload 仅提供明确接口。

## 目录与学习路线
1. `src/shared/resume.ts`：数据模型、文件版本与输入校验。
2. `src/renderer/src/store/resume.ts`：Zustand 状态和示例文档。
3. `src/renderer/src/App.tsx`：编辑、恢复草稿与保存流程。
4. `src/renderer/src/components/ResumePreview.tsx`：安全 Markdown 渲染。
5. `src/renderer/src/components/ResumePreview.module.scss`：主题与打印分页。
6. `src/preload/index.ts`：类型化桥接接口。
7. `src/main/index.ts`：系统对话框、文件读写和 PDF 服务。

## 数据与限制
- 简历库位于 Electron `app.getPath('userData')/library.json`，首次升级自动迁移旧 `draft.json` 并保留原件，不上传云端；链接仅在用户点击时用系统浏览器打开。
- 草稿使用临时文件 + rename 顺序写入。写入出错会提示；草稿损坏时暂停自动保存，保留原文件。
- 自动保存不创建历史快照；历史需手动保存。JSON 导入作为新简历加入，载入示例会替换当前文档，请先保存版本。
- 编辑区使用 useDeferredValue 延后预览优先级；没有承诺 16ms 延迟或 60fps，也没有性能测量结论。
- 长段落、超出一页的列表项仍可能跨页；分页规则不能保证任意内容不跨页。超长表格需要检查导出结果。
- 当前不包含任意 CSS 导入、AI、Word 导出、自动更新或云同步。

## 手动验收
1. 输入中文并切换主题，确认预览内容和字号同步。
2. 等到“已保存到本机”，关闭再打开，确认恢复内容。
3. 导出 JSON、修改内容、重新打开 JSON，确认恢复版式与内容。
4. 打开错误 JSON / 超大文件，确认提示错误且当前内容保留。
5. 添加多页内容、长网址、表格，导出 PDF 检查 A4 尺寸、分页、中文和文字可选性。
6. 输入 `<script>`、JavaScript 链接和远程图片，确认不执行、不加载。

## 多份简历与版本历史
- 侧栏支持新建、切换、复制、删除；编辑简历名称即可重命名。最多 30 份简历。
- 展开“版本历史”，填写备注并保存快照；相邻同内容不重复保存，每份最多保留最近 20 个快照。
- 比较选中快照与当前内容，包括 Markdown 变更区间及标题、主题、字号、行高差异。
- 恢复前先保存当前内容，可再从“恢复前自动备份”切回；删除简历会一并删除其历史，界面要求确认。
- 差异算法使用公共前后缀识别替换区间，按区间展示新增和删除，不保证最短编辑脚本。
- 简历库总文件上限 32 MB，写入使用串行队列及临时文件替换；文件损坏时暂停自动保存，不静默回退覆盖。
- “保存 JSON”仅备份当前文档，不包含整个简历库和版本历史；迁移机器时需另外备份 userData 中的 library.json。

### 新模块阅读顺序
1. `src/shared/library.ts`：v2 模型、校验、快照去重、恢复与差异比较。
2. `src/main/library-storage.ts`：旧草稿迁移、文件大小限制与串行写入。
3. `src/renderer/src/store/resume.ts`：多份简历状态转换。
4. `src/renderer/src/components/LibraryPanel.tsx`：列表与版本历史交互。

## 简历头像
- 在侧栏“简历头像”选择、更换或移除本地 PNG/JPEG（不超过 5 MB），支持证件照和圆形显示。
- 图片会缩小到最长边 360px 并重新编码为 PNG，采用内嵌数据保存，不依赖原图片路径。
- 头像随简历复制、JSON 备份、历史快照和版本恢复一起处理。旧版无头像文档无需手动迁移。
- PDF 导出等待头像解码完成。证件照按 26 × 32 mm 居中裁切显示，目前不支持手动调整裁切位置。

## 模块表单编辑
- 提供基本信息、求职意向、教育背景、工作经历、项目经历、技术能力、自我评价、实习经历、校园经历、荣誉证书、兴趣爱好和自定义模块。
- 点击模块名称配置对应字段，勾选控制显示；隐藏不删除数据，空模块不输出标题。模块可上移、下移和重命名，重复经历支持增加、删除条目。
- 新建简历默认使用空白表单。旧简历首次点击“开始模块配置”时，Markdown 原文保留在“原有内容”模块，不猜测并拆分历史文字。
- 表单统一生成 Markdown 供主题预览和 PDF 使用；JSON、简历库及快照同时保存字段、模块顺序和隐藏状态。
- Markdown 编辑是独立模式，当前不做任意 Markdown 的双向字段解析。切回已有表单前，先将 Markdown 保存为历史快照，再从表单重新生成内容。
- 表单模式单行字段按纯文本处理，详细描述支持 Markdown；最多 20 个模块，每模块最多 20 条经历，模块文本总量上限 200,000 字符。

## 工作区背景
侧栏“工作区背景”支持选择本地 PNG/JPEG（不超过 12 MB）、调整白色遮罩和恢复默认。图片最长边缩小至 2048px 后编码保存，外观配置单独位于 userData/appearance.json，重启后恢复；不进入简历、JSON 备份或 PDF。背景目前作用于右侧预览工作区。

## PDF 简历导入
- 顶部“导入 PDF”选择本地文件（最大 10 MB / 20 页），在确认窗口核对并修改提取文字，再创建新简历。
- 全程本地解析，原 PDF 不修改，取消导入不会写入或覆盖现有简历。导入后可继续编辑并导出新的 A4 PDF。
- 当前支持有文字层的 PDF；扫描件 / 图片 PDF 尚未支持 OCR，有密码的文件需先解密。
- 导入侧重文字重建，原布局、图片、头像、字体和表格样式不会原样保留；双栏顺序与特殊字符须人工核对。部分无文字页会明确提示。
- PDF.js worker、CMaps 和字体随应用离线打包。npm run dev / build 会自动准备本地资源，不依赖 CDN。

## 模板与纸面编辑
- 顶部“选择模板”提供经典单栏、分栏章节、简约居中、紧凑专业四套排版。应用模板只改样式，从模板新建会创建包含可替换示例内容的独立简历。
- 表单模式下点击右侧姓名、联系方式、章节标题、学校或项目等文字原位编辑，变化即时同步模块表单和自动保存。
- 单行按 Enter 完成，描述支持 Markdown，可按 Ctrl/Cmd+Enter 完成；Escape 撤销本次字段编辑。编辑提示和空字段不进入 PDF。
- Markdown 模式可点击正文块直接编辑 Markdown，保留原有模式切换保护；不将任意自由文本自动猜测为结构化字段。

## 导入识别、标准中文模板与字段隐藏
- PDF 导入确认后按规则拆分基本信息、教育、工作、项目等字段，保留“PDF 提取原文”快照，不覆盖原 PDF。
- 已导入到“原有内容”的旧简历，在模块表单中点击“识别为表单（新建副本）”。原件保留，识别后的副本使用标准中文模板。
- 规则识别并非无误，未知段落保留在其他信息、详细描述或自定义模块，请核对公司、职位、时间及段落归属。
- 每个模块的“显示字段”可单独关闭手机号、邮箱、薪资、日期等输入项，关闭后同时不显示在简历与 PDF，但原值仍保存在本地与备份中，可恢复显示。
- 标准中文模板参考居中姓名、黑色章节线、右侧日期和右上照片的常规排版；版式设置中支持预设与自定义主题色。
